about=GeoClick Capture is a lightweight location-verification and capture-log tool for field verification, map review and GIS quality assurance. Version 1.3.0 adds a tabbed Search & Capture workflow for place names and addresses through OpenStreetMap Nominatim, direct decimal coordinates, and OpenStreetMap or Google Maps URLs. Results can be reviewed, zoomed, previewed, copied, opened in external maps and added to the active capture session. Search captures store the input method, original query, provider, provider result ID, label, type, importance and OSM identifiers. Text searches can be restricted to Mozambique or another country and optionally to the current QGIS map extent. Requests use the QGIS network manager with safe redirects, caching, timeout, one transient retry, explicit OpenStreetMap attribution and rate limiting. Existing capabilities include QGIS 4 / Qt 6 support, automatic vertex-first and segment fallback snapping, sessions, operator/category/status/note fields, destination-layer selection, UTC and project context, reverse geocoding with progressive administrative fallback, record review, undo/delete/clear actions, and CSV, GeoJSON and GeoPackage export. There are no external Python dependencies.
