name=GeoClick Capture
description=Log map clicks to a point layer with WGS 84 and project coordinates, timestamps and optional reverse geocoding.
about=GeoClick Capture is a lightweight point-logging tool for field verification, map review and quality assurance. Each click creates an auditable record containing UTC capture time, WGS 84 latitude/longitude, original project coordinates, project CRS, the first vector layer below the click and an optional OpenStreetMap place name. Capture and export work locally. Reverse geocoding is disabled by default and uses the QGIS network manager; there are no external Python dependencies.
