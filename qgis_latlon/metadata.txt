about=GeoClick Capture is a lightweight location-verification and capture-log tool for field verification, map review and GIS quality assurance. Version 1.4.0 adds a Match & Verify tab that compares a selected search result with nearby features from one point layer or all visible point layers. The analysis combines geodesic distance and accent-insensitive name similarity into an explainable confidence score and High/Medium/Low duplicate-risk class. The plugin never chooses automatically: users can zoom to a candidate, link the existing feature or create a new point while preserving the evidence and decision in audit fields. Version 1.3.0 provides place and address search through OpenStreetMap Nominatim, direct decimal coordinates, and OpenStreetMap or Google Maps URLs. Existing capabilities include QGIS 4 / Qt 6 support, automatic vertex-first and segment fallback snapping, sessions, operator/category/status/note fields, destination-layer selection, UTC and project context, reverse geocoding, record review, undo/delete/clear actions, and CSV, GeoJSON and GeoPackage export. There are no external Python dependencies.
