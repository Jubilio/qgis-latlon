about=GeoClick Capture is a lightweight location-verification, capture-log and review tool for field verification, map review and GIS quality assurance. Version 1.6.0 adds a Review Queue with filters, multi-record decisions, reviewer comments, Approve, Reject, Needs changes and Reset pending actions, immutable JSON history, review iterations and CSV export. Decisions synchronise the operational status and preserve reviewer, UTC timestamp, comment and whether further review is required. Version 1.5.0 adds an Offline Gazetteer for UTF-8 CSV files and loaded QGIS point layers, including GeoPackage and database layers, with local name, alias and P-code search. Version 1.4.0 provides Match & Verify with duplicate-risk evidence. Version 1.3.0 provides Nominatim place search, coordinates and supported map URLs. The plugin supports QGIS 3.28+, QGIS 4 / Qt 6, snapping, sessions, reverse geocoding and CSV, GeoJSON and GeoPackage export without external Python dependencies.
