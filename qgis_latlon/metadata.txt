about=GeoClick Capture is a lightweight location-verification and capture-log tool for field verification, map review and GIS quality assurance. Version 1.5.0 adds an Offline Gazetteer tab that loads UTF-8 CSV files or uses any point layer already open in QGIS, including GeoPackage and database layers. The plugin automatically detects common fields for official names, aliases, P-codes, coordinates, place types and administrative names; searches them locally without Internet access; and can preview, zoom, match or add a selected record to the active capture session. Gazetteer source, record ID, P-code, official name, aliases, type, administrative hierarchy and source date are retained as audit fields. Version 1.4.0 provides Match & Verify with nearby-feature scanning, geodesic distance, name similarity, confidence scoring and duplicate-risk classification. Version 1.3.0 provides Nominatim place search, direct coordinates and supported OpenStreetMap/Google Maps URLs. Existing capabilities include QGIS 4 / Qt 6 support, automatic snapping, sessions, reverse geocoding, record review and CSV, GeoJSON and GeoPackage export. There are no external Python dependencies.
